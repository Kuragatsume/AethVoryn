## ⚡ Ключевые возможности

### 🪟 1. Windows-Style Desktop & Оконный менеджер
* **Многооконность с Edge Snap Assist**: свободное перемещение, изменение размеров с 8 сторон, примагничивание к краям экрана (50% лево/право, 100% разворот).
* **Виртуальные рабочие столы (WS: ВСЕ / 01 / 02 / 03)**: группировка и фильтрация открытых окон по задачам.
* **Прикреплённая панель (Command Rail)**: боковое меню всегда зафиксировано на экране и остаётся под рукой при любой высоте страницы.
* **Авто-скрытие интерфейса**: при максимизации окна элементы рабочего стола скрываются, не перекрывая кнопки управления.

### 🎥 2. Адаптивный 4K-Видеофон и Архитектурная Сетка
* **Динамическая высота**: страница адаптируется под пропорции любого загруженного видео (`--bg-video-height`) с плавной вертикальной прокруткой.
* **100% покрытие**: видео масштабируется без обрезки и чёрных полос (`object-cover` / `fill`).
* **Полноэкранная архитектурная сетка**: при выключенном видео сетка продолжается до самого нижнего пикселя экрана.

### 🔮 3. Интерактивная 3D-Голограмма
* **Перетаскивание зажатием ЛКМ**: чтобы переместить 3D-ядро, достаточно зажать левую кнопку мыши прямо на объекте и переместить его в любое место стола.
* **5 трёхмерных геометрий**: *Икосаэдр*, *Гиперкуб (Тессеракт)*, *Октаэдр (Кристалл)*, *Орбитальный Тор*, *Двойная Спираль*.
* **Параллакс-реакция на курсор**: гироскопические кольца и узлы вершин наклоняются вслед за движениями мыши.

### 🎵 4. Локальный Музыкальный Плеер и Радио
* **Прямое воспроизведение из папки**: потоковое чтение треков напрямую из `C:\Users\dakos\Downloads\MediaHuman\Music` без копирования и дублирования файлов.
* **Поддержка HTTP 206 Range**: мгновенный отклик и перемотка треков.
* **Встроенное Кибер-Радио**: Synthwave, Dark Ambient, Defcon Radio + процедурный нейро-генератор эмбиента.
* **Аудио-визуализатор**: живой спектральный эквалайзер в реальном времени.

### 🤖 5. ИИ-Ассистент (AI Co-Pilot) и Терминал (`AETH-SH`)
* **Окно `03` ИИ-Ассистент**: авто-суммаризация новостей в один клик, планировщик задач по вашим заметкам и поддержка Gemini API.
* **Окно `04` Терминал**: консоль со встроенными командами (`help`, `sysinfo`, `news`, `notes`, `note`, `calc`, `weather`, `crypto`, `matrix`).
* **Командная палитра `Ctrl + K`**: глобальный поиск по сайту, запуск окон и встроенный калькулятор.

### 🎨 6. Темы оформления и Настройки по категориям
* **Темы**: *Тёмная*, *Белая* (с автоматической адаптацией контраста), *Серая*, *Графит и Сталь*, *Холодный Кобальт*, *Тёмный Изумруд*, *Строгая Бронза* + создание собственных тем.
* **Категоризированные настройки**: окно разделено на 6 удобных разделов (Темы, Фон, 3D-объект, Музыка, Окна, Система).
* **Экспорт / Импорт (.JSON)**: резервное копирование всех заметок, сайтов и настроек одним файлом.

## 🚀 Быстрый старт

### 1. Автоматическая установка (Windows)
Просто запустите скрипт:
```cmd
install-dependencies.bat
```
Скрипт проверит наличие Node.js, установит все зависимости (`npm install`) и соберёт продакшен-бандл.

---

### 2. Ручная установка
```bash
# Клонирование репозитория
git clone https://github.com/Kuragatsume/AethVoryn.git
cd AethVoryn

# Установка зависимостей
npm install

# Сборка проекта
npm run build

# Запуск локального сервера (порт 3456)
npm run start
```
Откройте в браузере: **`http://localhost:3456`**

## 🔒 Конфиденциальность и Данные
* Музыкальные и видеофайлы **не загружаются на удалённые серверы** и воспроизводятся локально на вашем компьютере.
* Заметки, открытые сайты и пользовательские темы сохраняются локально в хранилище вашего браузера (`localStorage` / `IndexedDB`).
* Полный профиль можно сохранить или перенести через кнопку **«Экспорт .JSON»** в разделе Настроек.
